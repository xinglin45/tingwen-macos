# 听文（tingwen-macos）

原生 macOS 文本朗读应用，使用本机已经下载的系统声音。无需 Apple 开发者账号、付费会员或 API Key。

仓库提供源码。首次使用请先按下方“构建与运行”生成 `dist/听文.app`。

## 使用

1. 双击 `dist/听文.app`。也可把它拖到“应用程序”文件夹。
2. 点击“打开文本文件”，或把文件拖入窗口。
3. 点击右上角“朗读设置”选择声音，默认“跟随系统声音”。也可以手动选择已安装的“月（高音质）”等声音。
4. 点击“开始朗读”。全局快捷键默认为 **Control + Option + Space**。
5. 在“朗读设置”中修改快捷键，按下新组合键，再点击“保存”。组合键至少包含 Control、Option 或 Command；占用冲突会显示提示。

朗读过程中可以暂停、继续、调整语速和音量、拖动进度、回到开头。点击或选中文字后，可“从选中处朗读”；也可通过文本右键菜单操作。声音或语速改变时，从当前词重新开始应用新设置。

关闭主窗口后，菜单栏图标和全局快捷键仍然有效。选择菜单栏“退出听文”或按 Command + Q 才会退出。无需授予辅助功能、录音或语音识别权限。

## 章节与搜索

- 侧栏提供“目录”和“搜索”两种视图，点击右侧顶部的侧栏按钮可收起或展开。
- 自动识别独立一行的 `第1章 标题`、`第一章 标题`、`第１章：标题`、章/回/节/卷/部/篇、`Chapter 1`、`Chapter IV`，以及序章、楔子、尾声等常见标题。中文章节标记后可为空，或使用空格、冒号等分隔标题。没有这些标题时，尝试 Markdown 标题；仍未识别时按“全文”展示。
- 章节前的作品介绍保留为“作品信息 / 前言”，正文和章节顺序不会被删改。标题识别依赖文本格式，无法推断没有独立标题的章节。
- 右侧仅展示当前章节。朗读完本章后自动展示并朗读下一章，最后一章读完才结束。目录中的选中项也会跟随切换。
- 点击目录、上一章、下一章或搜索结果，会停止当前朗读。点击播放后从新位置继续。底部进度条表示本章进度，同时显示全书进度；“回到本章开头”只重置当前章节。
- 输入关键词或按 **Command + F** 搜索整份文件。搜索为普通文字匹配，忽略英文大小写；同一章节的结果合并显示匹配次数和正文片段。
- 点击结果会打开该章节，滚动到第一处匹配，并以黄色高亮该章全部匹配词。随后播放会从第一处匹配开始。清除搜索会移除高亮。搜索在后台执行，快速修改关键词时会取消过期搜索。

## 文件格式

- 纯文本：TXT、Markdown、CSV、TSV、JSON、JSONL、LOG、XML、YAML、TOML、INI、CONF、SRT、VTT，以及常见代码文本。
- 编码：UTF-8、带 BOM 的 UTF-16 / UTF-32、GB18030（兼容常见 GBK 中文文本）。
- 文档：RTF、HTML、DOCX、可提取文字的 PDF。仅朗读提取的文字，Markdown 标记会保留。
- 最大 20 MB。扫描 PDF 不含文字，需要先进行 OCR。文档阅读顺序取决于系统提取结果。

打开文件不会修改原文件，不会自动开始发声。应用在本机保存声音收藏、声音、语速、音量、快捷键和侧栏显示偏好；关闭应用后不保存文档内容或朗读位置。

首次使用可点击“试读示例”加载内置说明，再点击播放。

## 声音

声音来自 macOS 语音合成框架。到“系统设置 → 辅助功能 → 阅读与朗读 → 系统声音”下载和管理声音，再返回应用点击刷新。

朗读设置提供“推荐 / 收藏 / 全部已安装”三个声音列表。推荐中文女声黎潋、中文男声瀚（Han）、英文女声 Ava（美式）、英文男声 Jamie（英式），均以高音质版本为目标。推荐项是候选清单，是否安装以本机语音框架的返回结果为准，系统若不提供对应版本则暂不可用。

点击空心五角星收藏声音，黄色实心五角星表示已收藏；在收藏列表再次点击星标即可移除。收藏保存在本机，退出重开仍保留，声音卸载后仍可查看、移除或进入下载设置。收藏不会改变当前朗读声音。全部已安装和收藏列表支持按名称、语言搜索。

未安装项的“前往下载”打开系统的“阅读与朗读”，并在听文中显示对应声音和下载步骤。macOS 公开语音接口不提供直接下载声音的方法，需在系统声音管理页下载。回到应用或收到声音列表变化通知后会自动刷新，也可手动刷新；下载不会自动切换当前声音。

AVFoundation 的默认语言声音与“系统声音”在部分 macOS 版本上可能不一致。应用读取系统声音选择（只读），并保留公开 API 的回退方式。系统偏好键在未来可能改变；如果未能读取，请在应用里手动选择“月（高音质）”或其他已安装声音。个人声音的授权不在本版本范围内。

## 构建与运行

需要 macOS 14 或更新版本，以及 Xcode 或包含 Swift 编译器的命令行工具。

```sh
git clone https://github.com/xinglin45/tingwen-macos.git
cd tingwen-macos
bash scripts/build.sh
open dist/听文.app
```

运行核心测试：

```sh
swift test
```

也可以双击 `构建应用.command`。构建过程使用本地 ad-hoc 签名：`codesign --sign -`，无需证书或账号。当前构建针对本机 CPU 架构；无需安装额外依赖。

生成的 `dist/`、`.build/` 和本机 SwiftPM 配置不纳入版本管理。

本地运行无需付费开发者计划。向其他人分发、Apple 公证或上架 App Store 是另一个流程；当前产物为本机使用版本。

## 验证

`swift test` 验证文本编码、HTML 提取、长文本分段和 Unicode 范围。可在退出应用后运行以下集成检查：

```sh
./dist/听文.app/Contents/MacOS/ListenText --verify "$PWD/dist/verification.json"
```

检查在实际应用中运行，使用音量为零的系统语音合成，验证文件导入、朗读回调、暂停、继续、跳转、停止、自然结束、快捷键注册、自动跨章、章节搜索与高亮，以及声音名称、推荐类别、收藏持久化、移除和未安装声音选择保护。可追加 `--verify-book '/path/to/book.txt'` 检查实际长篇文件的章节识别和全文搜索。结束时恢复原偏好并退出，结果写入指定 JSON 文件。
