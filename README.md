# 听文（tingwen-macos）

原生 macOS 文本朗读应用，使用本机已经下载的系统声音。无需 Apple 开发者账号、付费会员或 API Key。

仓库提供源码。首次使用请先按下方“构建与运行”生成 `dist/听文.app`。

## 使用

1. 双击 `dist/听文.app`。也可把它拖到“应用程序”文件夹。
2. 点击“打开文本文件”，或把文件拖入窗口。
3. 点击右上角“朗读设置”选择声音，默认“跟随系统声音”。也可以手动选择已安装的“月（高音质）”等声音。
4. 点击“开始朗读”。全局快捷键默认为 **Control + Option + Space**。
5. 在“朗读设置”中修改快捷键，按下新组合键，再点击“保存”。组合键至少包含 Control、Option 或 Command；占用冲突会显示提示。

朗读过程中可以暂停、继续、调整语速和音量、拖动进度、回到开头。点击或选中文字后，可“从选中处朗读”；也可通过文本右键菜单操作。声音或语速改变时，从当前词重新开始应用新设置。

关闭主窗口后，菜单栏图标和全局快捷键仍然有效。选择菜单栏“退出听文”或按 Command + Q 才会退出。无需授予辅助功能、录音或语音识别权限。

## 书架与续读

- 左侧栏提供“书架 / 目录 / 搜索”。通过“添加文本文件”一次选择多个文件，或拖入多个文件，打开和添加成功的文件会自动保存到书架。同一文件重复添加不会新增条目，内置试读示例不加入书架。
- 书架显示文件名、章节、全书进度、上次阅读时间；支持按文件名查找，按最近阅读 / 打开时间排序。
- 点击书架文件，会打开对应章节、滚动到上次播放位置，标记续读起点；点击“继续朗读”才开始发声。启动时恢复上次打开的书架文件，保持未播放状态。
- 每个文件分别保存进度，朗读中最多约 2 秒保存一次，暂停、停止、切换文件、退出时立即保存。主动拖动进度或回到开头也会更新记录；仅浏览章节、搜索结果或选中文字不会覆盖续读位置。
- 每行的管理菜单或右键菜单可重新定位文件、移除条目。书架顶部管理菜单支持刷新文件状态、清空书架（需确认）。移除和清空会删除对应阅读记录，不会删除磁盘原文件；移除当前文件会停止朗读并关闭正文。
- 使用系统文件书签尽量跟踪移动、重命名。失效条目仍保留并显示“文件不可用”，可以重新定位；内容改变时用章节标题和附近文字尝试恢复，无法可靠匹配则提示并回到对应章节开头。
- 书架保存在本机 `~/Library/Application Support/ListenText/library.json`，应用更新后继续保留。异常退出可能重复朗读最近约 2 秒的内容。

## 章节与搜索

- 侧栏中的“目录”和“搜索”视图用于当前文件，点击右侧顶部的侧栏按钮可收起或展开。
- 自动识别独立一行的 `第1章 标题`、`第一章 标题`、`第１章：标题`、章/回/节/卷/部/篇、`Chapter 1`、`Chapter1: Title`、`Chapter IV`，以及序章、楔子、尾声等常见标题。兼容章号后无空格的 `第一章拍花造畜`、括号包裹的 `【第1章 标题】`、全角空格和常见不可见格式符；也兼容连贯数字编号的 `001 标题`、`1. 标题`、`一、标题`。没有这些标题时，尝试 Markdown 标题；仍未识别时按“全文”展示。
- 章节前的作品介绍保留为“作品信息 / 前言”，正文和章节顺序不会被删改。标题识别依赖文本格式，无法推断没有独立标题的章节。
- 右侧仅展示当前章节。朗读完本章后自动展示并朗读下一章，最后一章读完才结束。目录中的选中项也会跟随切换。
- 点击目录、上一章、下一章或搜索结果，会停止当前朗读。点击播放后从新位置继续。底部进度条表示本章进度，同时显示全书进度；“回到本章开头”只重置当前章节。
- 输入关键词或按 **Command + F** 搜索整份文件。搜索为普通文字匹配，忽略英文大小写；同一章节的结果合并显示匹配次数和正文片段。
- 点击结果会打开该章节，滚动到第一处匹配，并以黄色高亮该章全部匹配词。随后播放会从第一处匹配开始。清除搜索会移除高亮。搜索在后台执行，快速修改关键词时会取消过期搜索。

## 文件格式

- 纯文本：TXT、Markdown、CSV、TSV、JSON、JSONL、LOG、XML、YAML、TOML、INI、CONF、SRT、VTT，以及常见代码文本。
- 编码：UTF-8、GB18030（兼容 GBK / GB2312）、Big5、UTF-16 / UTF-32。优先识别 BOM 和严格 UTF-8；无 BOM 的 UTF-16/32 结合字节结构判断，GB18030 与 Big5 结合无损往返和文字可读性比较。纯中文且无 BOM 等模糊情况可手动指定编码。
- 文档：RTF、HTML、DOCX、可提取文字的 PDF。仅朗读提取的文字，Markdown 标记会保留。
- 最大 20 MB。扫描 PDF 不含文字，需要先进行 OCR。文档阅读顺序取决于系统提取结果。

打开文件不会修改原文件，不会自动开始发声。应用在本机保存声音收藏、声音、语速、音量、快捷键和侧栏显示偏好；书架会保存文件引用及每个文件的朗读位置。非 UTF-8 文本会先自动生成本机 UTF-8 副本，再加入书架；原文件保持不变，正常 UTF-8 文本无需复制。为应对原文件修改，会保存续读位置附近的一小段文字用于定位。

非 UTF-8 文本的转换副本存放在 `~/Library/Application Support/ListenText/ConvertedTexts/`。书架菜单提供“显示 UTF-8 副本”；打开原文件时重新检查内容，移除或清空书架会清理不再使用的转换副本，其他条目仍在使用的副本会保留。

添加文件窗口左下角点击“显示选项”，可选择“文本编码”，默认自动识别。书架每行管理菜单的“文本编码”可指定编码重新读取，并为该文件记住选择；选择“自动识别”可恢复自动模式。解码失败的文件不会加入书架，也不会使用替换符进行有损转换。文件已经经过错误的有损转换时，丢失的文字无法自动恢复，需要取得原始文件。

首次使用可点击“试读示例”加载内置说明，再点击播放。

## 声音

声音来自 macOS 语音合成框架。到“系统设置 → 辅助功能 → 阅读与朗读 → 系统声音”下载和管理声音，再返回应用点击刷新。

朗读设置提供“推荐 / 收藏 / 全部已安装”三个声音列表。推荐中文女声黎潋、中文男声瀚（Han）、英文女声 Ava（美式）、英文男声 Jamie（英式），均以高音质版本为目标。推荐项是候选清单，是否安装以本机语音框架的返回结果为准，系统若不提供对应版本则暂不可用。

点击空心五角星收藏声音，黄色实心五角星表示已收藏；在收藏列表再次点击星标即可移除。收藏保存在本机，退出重开仍保留，声音卸载后仍可查看、移除或进入下载设置。收藏不会改变当前朗读声音。全部已安装和收藏列表支持按名称、语言搜索。

未安装项的“前往下载”打开系统的“阅读与朗读”，并在听文中显示对应声音和下载步骤。macOS 公开语音接口不提供直接下载声音的方法，需在系统声音管理页下载。回到应用或收到声音列表变化通知后会自动刷新，也可手动刷新；下载不会自动切换当前声音。

AVFoundation 的默认语言声音与“系统声音”在部分 macOS 版本上可能不一致。应用读取系统声音选择（只读），并保留公开 API 的回退方式。系统偏好键在未来可能改变；如果未能读取，请在应用里手动选择“月（高音质）”或其他已安装声音。个人声音的授权不在本版本范围内。

## 构建与运行

需要 macOS 14 或更新版本，以及 Xcode 或包含 Swift 编译器的命令行工具。

```sh
git clone https://github.com/xinglin45/tingwen-macos.git
cd tingwen-macos
bash scripts/build.sh
open dist/听文.app
```

运行核心测试：

```sh
swift test
```

也可以双击 `构建应用.command`。构建过程使用本地 ad-hoc 签名：`codesign --sign -`，无需证书或账号。当前构建针对本机 CPU 架构；无需安装额外依赖。

生成的 `dist/`、`.build/` 和本机 SwiftPM 配置不纳入版本管理。

本地运行无需付费开发者计划。向其他人分发、Apple 公证或上架 App Store 是另一个流程；当前产物为本机使用版本。

## DMG 安装镜像

```sh
bash scripts/package-dmg.sh
```

脚本重新构建应用，生成 `dist/Tingwen-v<版本>-macOS-<架构>.dmg` 和对应的 `.sha256` 校验文件。镜像包含听文应用、指向应用程序文件夹的入口和安装说明；将应用拖入该入口即可安装。可以将 DMG 作为 GitHub Release 附件上传。

镜像针对构建机器的 CPU 架构；`arm64` 用于 Apple Silicon，`x86_64` 用于 Intel。DMG 仅提供安装包装，应用仍为本地 ad-hoc 签名，未经过 Developer ID 签名或 Apple 公证。从互联网下载后，macOS 可能阻止首次打开。

## 验证

`swift test` 验证文本编码、HTML 提取、长文本分段、Unicode 范围、书架存储及续读位置恢复。可在退出应用后运行以下集成检查：

```sh
./dist/听文.app/Contents/MacOS/ListenText --verify "$PWD/dist/verification.json"
```

检查在实际应用中运行，使用音量为零的系统语音合成，验证文件导入、朗读回调、暂停、继续、跳转、停止、自然结束、快捷键注册、自动跨章、章节搜索与高亮，以及声音名称、推荐类别、收藏持久化、移除和未安装声音选择保护。还使用隔离的临时书架验证多文件导入、重复文件、续读恢复、文件重命名与修改、重新定位、移除和清空，以及 GB18030、Big5、UTF-16 自动导入与 UTF-8 副本、手动编码持久化和共享副本清理，不改变实际书架。可追加 `--verify-book '/path/to/book.txt'` 检查实际长篇文件的章节识别和全文搜索。结束时恢复原偏好并退出，结果写入指定 JSON 文件。
